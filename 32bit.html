AcreetionOS32

32-bit (i686) builds of AcreetionOS for legacy hardware. Built from the Arch Linux 32-bit repositories. These images are untested — we build them so they exist, but we may not know everything about how they behave on every system.

⬇️ Latest ISO

ISOs are built every 7 days via GitHub Actions and stored on Cloudflare R2.

View Latest Build Build Scripts

ISOs uploaded to Cloudflare R2 — free downloads, no account required.

⚠️ Notes

These builds are not tested. We compile them from upstream Arch Linux 32-bit repositories so they exist for those who need them — testing, education, legacy hardware, automated pipelines. We do not run QA on them.

32-bit hardware and software combinations vary widely, and our testing capacity is limited. If you run into issues, community knowledge and the Arch Linux 32-bit project are your best resources.

🛠 Build Process

  • Clones the AcreetionOS source repository
  • Creates a custom mkarchiso profile targeting i686 architecture
  • Uses the Arch Linux 32-bit package repositories
  • Builds via mkarchiso producing a bootable ISO
  • Uploads the resulting ISO to Cloudflare R2 storage

Builds run automatically every 7 days. Source: github.com/spivanatalie64/acreetionos32
