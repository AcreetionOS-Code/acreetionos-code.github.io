AcreetionOS32

32-bit (i686) builds of AcreetionOS for legacy hardware. Built from the Arch Linux 32-bit repositories (archlinux32.org). These images are untested — we build them so they exist, but we may not know everything about how they behave on every system.

Builds auto-upload to Cloudflare R2 — free to download, no account needed.

⚠️ Important Notes

These builds are not tested. We compile them from the upstream Arch Linux 32-bit repositories so they exist for those who need them — testing, education, legacy hardware, automated pipelines. We don't run QA on them.

32-bit hardware and software combinations vary widely, and our testing capacity is limited. If you run into issues, community knowledge and the Arch Linux 32-bit project are your best resources.

How It's Built

The build process:

  • Clones the AcreetionOS source repository
  • Patches the build profile for i686 architecture
  • Builds using mkarchiso with Arch Linux 32-bit repositories
  • Uploads the resulting ISO to Cloudflare R2

Builds run automatically every 7 days via GitHub Actions.
