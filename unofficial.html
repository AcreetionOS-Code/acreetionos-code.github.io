Autobuild Pipeline

All community editions are automatically rebuilt every Monday at 6:00 UTC via GitHub Actions. The pipeline clones the main AcreetionOS source, applies edition-specific patches, builds a bootable ISO via mkarchiso inside Docker, and uploads the finished ISO to Cloudflare R2 for free downloads.

  • Clones the main AcreetionOS source repository
  • Applies edition-specific patches (desktop environment, packages, configs)
  • Builds a bootable ISO via mkarchiso inside a Docker container
  • Uploads the finished ISO to Cloudflare R2 for free downloads
