Hey! I'm AIDEN, your onboard AcreetionOS assistant. Ask me anything about the project — installation, features, requirements, or team. I work completely offline! ✨

🎤 Voice Commands

  • Tap 🎤 — starts listening. Speak your question.
  • "delete" — removes the last word you said.
  • "clear" — clears the text field.
  • "send" — sends the message to AIDEN.
  • "stop" — stops listening.
  • 🤖 AI Mode — AIDEN uses OpenRouter AI if you set an API key. Without one, the offline knowledge base is used.
  • 🔊 TTS — AIDEN reads answers aloud. Toggle on/off.
