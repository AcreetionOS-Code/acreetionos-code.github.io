Daily AcreetionOS Update -- November 21, 2026

November 21, 2026

New acreetionos-wallpapers repo ships GitLab-backed backgrounds

AcreetionOS finally has a proper home for its wallpapers. A brand-new acreetionos-wallpapers repository landed today with an initial commit and a backgrounds submodule that tracks the AcreetionOS GitLab instance, so the distro's whole visual identity is now versioned like everything else we build.

Development That wasn't the only win in the desktop layer. In AcreetionOS-Xlibre, the bottom-bar icon is clickable again after a fix that squashed an annoying dead-click bug, and the image now ships the latest Electron for new users so a fresh install starts current instead of a week behind. Small commits, sure, but they're the kind that make a first boot feel deliberate rather than accidental. The full rundown always lives in the changelog at https://acreetionos.org/changelog.html.

Community Out in the wider Linux world, the news kept coming. Beyls is wrapping up LLVM's relicensing effort, which should make the toolchain a lot friendlier to build against going forward. Vim Classic dropped 8.3.1, and AlmaLinux pushed a Friday batch of security updates covering bind, bubblewrap, freerdp, grafana, and more. None of it touches your AcreetionOS install this morning, but it's a decent reminder that "stable" is a moving target upstream — patches don't apply themselves.

Tip of the day If you like to rotate your desktop backgrounds, point your picker straight at the new wallpapers repo instead of digging through old ISO files by hand — the submodule keeps the collection in sync with what actually ships. And if you ever wonder why a setting behaves the way it does, the wiki at https://acreetionos.org/wiki.html documents the reasoning behind our Cinnamon and XLibre choices. Still need to flash a fresh copy? The instructions are waiting at https://acreetionos.org/flash.html.

Two devs, one very tidy repo, and a purple wallpaper finally accounted for. Back at it tomorrow.
