Daily AcreetionOS Update -- November 20, 2026

November 20, 2026

Subject: Calamares init failure fixed — shellprocess2 sequence entry was the culprit

The installer boots again. Darren (cobra3282000) found and fixed the shellprocess2 sequence entry that was killing Calamares at init — the kind of single misplaced line that makes a whole ISO die before you ever reach the partition screen.

Development

The fix landed alongside a broader refresh of the Calamares files, so the installer config is now consistent rather than half-patched. Over in PRJCTNatalie, two branches moved: features/foundation-scaffold laid down the Natalie AI agent foundation, and features/local-ai-deploy added hardware detection plus a deploy-local-ai path built on llama.cpp. Also worth a look: the fences screen bug got another pass, and 1.0.2 is now described in the commit log as "should be 100 percent now." We've heard that before, but this time there were two rounds of fixes on both MacJunkins/fences and cobra3282000/fences. Full history is at https://acreetionos.org/changelog.html.

Community

Arch pushed a heavy news day: PHP 8.6.0 is out with a new polling API, and there are four PHP security releases covering critical vulnerabilities — 8.5.13 among them. PostgreSQL 19 also landed. If you're running PHP anywhere on an AcreetionOS box, update today rather than this weekend, because the word "critical" is doing real work here. Natalie also made the initial commit to acreetionos-wallpapers, so expect new desktop art in the pipeline.

Tip of the day

Calamares runs modules in the exact order listed in the sequence in settings.conf. If shellprocess2 sits after something that depends on it, init fails silently and you get a blank or frozen installer with no obvious error. When you're editing sequence entries, run the installer with calamares -d and read the startup output — it names the module that failed. The docs at https://acreetionos.org/docs.html cover the build side, and the wiki has the packaging notes if you want to test a patched ISO yourself. Grab a fresh build from https://acreetionos.org/flash.html and tell us if the install path feels smoother.
