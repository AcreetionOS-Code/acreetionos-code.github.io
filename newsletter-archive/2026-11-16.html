Daily AcreetionOS Update -- November 16, 2026

November 16, 2026

Subject: AcreetionOS CI now publishes ISOs to the real public ISO server

The build pipeline finally grew up: AcreetionOS CI now ships finished ISOs straight to the real public ISO server over SSH, so a green build means a downloadable image instead of a file sitting on someone's machine waiting for a human. Darren landed it in two commits, including the unglamorous part — setting GIT_STRATEGY: none so the publish job stops re-checking out the repo before it copies the artifact.

Development

The same cleanup pass touched calamares-config, where a bad shellprocess2 sequence entry was causing Calamares to fail at init — that one's fixed, and the Wayland configs got a refresh in calamares-config-wayland. There's also a brand-new repo, firefox-fix, with an initial commit that restores Firefox window position handling on Linux. Natalie, meanwhile, scaffolded the Natalie AI agent foundation in PRJCTNatalie and added hardware detection plus deploy-local-ai via llama.cpp as a feature branch. Two devs, one distro, still shipping.

Community

Upstream kept us busy: kernel 7.4-rc3 dropped and Linus called it "fairly normal, with drivers (networking and…)" — his words, not ours. XRAID was announced, bringing declustered parity RAID to zoned XFS, which is worth a read if you care about storage that doesn't fall over. Friday's security round covered firefox, kernel, .NET, and openjdk across the usual distros; if you're running anything long-lived, patch it. Full details land on the changelog at https://acreetionos.org/changelog.html as they're packaged.

Tip of the day

If a recent install died during Calamares init, it wasn't you — it was that shellprocess2 sequence entry. Grab a fresh image from https://acreetionos.org/flash.html, verify the checksum before you write it, and the installer should behave. Writing from another OS is easiest with AcreetionMediaWriter, and the steps are documented at https://acreetionos.org/docs.html.

That's it from Spokane. Build green, mirror fed, server intact — for now.
