Daily AcreetionOS Update -- November 02, 2026

November 02, 2026

AcreetionOS now ships kernel 7.2.15 stable

Greg Kroah‑Hartman just tagged 7.2.15 as the final kernel release for the long‑term stable series, wrapping up the 7.2 cycle and giving AcreetionOS users a polished, bug‑tested kernel. Natalie and Darren have already merged 7.2.15 into the development branch, so the next ISO will boot with the freshly‑released kernel right out of the box.

Development The team finished the intelligence sync commit on 2026‑11‑01, pulling in the latest newsletter archive, wiki guides, and feed updates into acreetionos-code.github.io. This keeps the documentation and community resources in sync for everyone who visits the site. The carousel feature now supports a zoomable blow‑up viewer and continuous autoplay, giving visitors a smoother experience when browsing project screenshots.

Community The kernel prepatch 7.4‑rc1 hit the tree this week, signaling the start of the next development cycle and giving the AcreetionOS maintainers a preview of upcoming features. Meanwhile, a wave of security updates from AlmaLinux (including .NET runtimes, curl, bind, and more) were released on Saturday, and users are encouraged to run the updated packages. For those interested in the security side, the Hacktron blog posted an in‑depth look at how a compromise could have plagued Bash, a useful read for anyone who builds from source. Check the updated package list in the changelog at https://acreetionos.org/changelog.html.

Tip of the day When creating a live USB, the AcreetionOS MediaWriter now supports drag‑and‑drop imaging from any modern OS, eliminating the need for third‑party tools. Verify the SHA‑256 hash printed on the download page (https://acreetionos.org/flash.html) before you write the image to avoid corruption. This quick check saves time and ensures a clean boot every time. The wiki at https://acreetionos.org/wiki.html has a step‑by‑step guide for custom kernel configuration if you want to try the 7.4‑rc1 prepatch.
