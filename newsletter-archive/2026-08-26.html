Daily AcreetionOS Update -- August 26, 2026

August 26, 2026

AcreetionOS CI now publishes ISOs automatically from the immutable pipeline, cutting release friction for the cinnamon-XLibre spin.

Development Natalie Spiva pushed two CI fixes into acreetionos-code/acreetionos-immutable: per-pipeline staging dirs to avoid publish races between concurrent builds, and a relative symlink for latest.iso so it resolves on the host web root. Both changes mean the build server can stamp new nightlies without manual intervention — Darren Clift’s calamares work now flows straight into flash-ready images on https://acreetionos.org/flash.html.

Community Vanilla OS 3 dropped this week, an immutable desktop built for people who want arch without the suffering — same energy, honestly. On our own GitLab, cobra3282000 pushed initial releases for dl380g7-boot-decoded, mesa-software-rendering, and mds-core-wall, plus natalie/bash2bat got its first script and secret-detection configured in .gitlab-ci.yml. The changelog at https://acreetionos.org/changelog.html has all the gritty detail.

Tip of the day Flashing a new nightly? Use the relative latest.iso symlink on the download page instead of hunting commit hashes — it always points to the most recent successful build from the cinnamon-XLibre pipeline.
