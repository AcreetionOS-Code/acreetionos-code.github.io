AcreetionOS Update — June 25, 2026

June 25, 2026

Our continuous integration pipeline has just been fine-tuned again, with recent changes making our release process even more reliable and efficient, and you can find all the details on our changelog page at https://acreetionos.org/changelog.html. This is a great example of how our community-driven development process is always improving, and we're excited to see the impact it will have on our users.

Development The development team has been hard at work, with recent commits like the use of per-pipeline staging directories to avoid publish races between concurrent builds, and the use of relative symlinks for latest.iso so it resolves on the host web root. These changes will help ensure that our users always have access to the latest and most stable versions of our OS, and you can learn more about our development process on our wiki at https://acreetionos.org/wiki.html.

Community Our community has been actively discussing the latest software releases, including the recent release of Emacs 31.1, which brings many new features and improvements. We're also keeping up with the latest security updates, including those issued on Monday, and our stable kernel set from Sunday, which includes versions 7.1.10 and 6.18.46. For more information on how to stay up-to-date with the latest security updates, check out our documentation at https://acreetionos.org/docs.html. And if you're looking for the latest ISO, you can always find it at https://acreetionos.org/flash.html.
