Daily AcreetionOS Update -- September 18, 2026

September 18, 2026

Calamares installer config got a real-world tune-up this week: older NVIDIA GPUs now work on first boot, and the default gfxmode switched from native 4K to 1080p so installs on lower-resolution displays actually look right. cobra3282000 landed both commits in cobra3282000/calamares-config, which means your first boot experience just got smoother whether you are on legacy hardware or a modern display.

Development picked up speed on a few fronts. The geocode-glib update conflict that broke some installed systems is resolved via the repair merge -- if you hit dependency issues after a recent update, pull the latest and rebuild. natalie pushed two GitLab security hardening commits to natalie/my-politecal-stances (Secret Detection and SAST now configured in .gitlab-ci.yml), pinned v0.3.0 archive checksums in natalie/us-infra-hub, and added an MCP stdio server to the infra hub. acreetionos-code/acreetionos-immutable also fixed its release workflow -- a block-scalar indentation bug in release.yml was breaking validation, now corrected.

Community news: GNOME 51 shipped with performance improvements and offscreen rendering fixes -- worth watching if you run GNOME alongside Cinnamon. AlmaLinux issued Thursday security updates covering .NET 10.0/8.0/9.0, corosync, firewalld, kernel, kernel-rt, nginx:1.26, and more -- check https://acreetionos.org/changelog.html for what applies to your setup.

Tip of the day: If you are writing an AcreetionOS image to USB from Windows or macOS, use AcreetionMediaWriter at https://acreetionos.org/flash.html -- it works from any OS, no need to dig out a Linux machine just for flashing.
