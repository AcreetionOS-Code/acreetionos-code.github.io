Daily AcreetionOS Update -- October 27, 2026

October 27, 2026

Subject: acreetion-surf v2.0.0 lands — Natalie's browser hits a major milestone

Natalie just tagged acreetion-surf v2.0.0, the first proper release of the project's own WebKitGTK browser after months of quiet iteration. It's fast, minimal, and built on the same engine that powers Epiphany — but stripped of the GNOME dependencies that usually come with it.

Development The bigger desktop shift this week came from Darren: the Calamares Wayland config now forces a Wayland session by default, and lightdm-slick-greeter replaces the previous greeter to stop a display-manager crash that bit a few testers on Nvidia. Both changes are in the ISO pipeline at https://acreetionos.org/flash.html and will show up in the next build. Meanwhile the new firefox-fix package restores window-position memory on Linux — a small quality-of-life win that upstream has left broken for years.

Community Discord regulars have been stress-testing the Wayland default on everything from older Intel iGPUs to fresh AMD cards; the consensus so far is "surprisingly stable." If you hit a regression, the changelog at https://acreetionos.org/changelog.html tracks the exact package versions so you can bisect or report with precision.

Tip of the day If you're on the new Wayland default and need an X11 app (Steam, some Electron things), run it with GDK_BACKEND=x11 — or just log into the Cinnamon X11 session from the greeter. Both paths are supported; Wayland is merely the new first choice.
