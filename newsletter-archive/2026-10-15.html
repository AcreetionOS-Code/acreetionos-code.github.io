Daily AcreetionOS Update -- October 15, 2026

October 15, 2026

A sneaky YAML block-scalar indentation bug in acreetionos-immutable's release.yml was silently breaking our CI release validation, and today it's fixed. The same commit also tweaked the release job to pass -R to gh release create, preventing an unwanted source checkout during releases.

Development The acreetionos-immutable team tracked down the indentation issue that was failing workflow validation, and they've adjusted the release job so it no longer tries to check out source when creating a GitHub release. Over in acreetionos-code, we synced up the newsletter, archive, wiki guides, and feed for October 14, keeping the documentation current. The AcreetionOS-Xlibre branch got some quiet updates as well, and we re-triggered the GitLab mirror after a deploy key fix, which means your GitLab clones should be syncing smoothly again. You can track all the nitty-gritty in the changelog at https://acreetionos.org/changelog.html.

Community In bigger news, BetaNews ran a piece calling AcreetionOS the easy-to-use alternative to Windows 10/11, which is exactly the kind of practical recognition we want. How-To Geek published a personal essay about finally giving up on the Arch User Repository, and Phoronix reported on a prominent Arch Linux developer resigning after a decade. It's a reminder that the ecosystem is always shifting, but AcreetionOS is built to be the stable, user-friendly layer on top of all that motion. We're also keeping an eye on the Linux kernel news, with seven stable kernels dropping Thursday including a fix for a critical vulnerability.

Tip of the day If you're still running Windows 10 or 11 and curious about switching, the easiest path is to grab the latest AcreetionOS ISO from https://acreetionos.org/flash.html, write it to a USB with the AcreetionMediaWriter, and boot it live. No commitment, no data loss, just a test drive with the Cinnamon desktop. If it feels right, the Calamares installer makes the actual install painless.
