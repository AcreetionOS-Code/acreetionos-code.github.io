Daily AcreetionOS Update -- November 11, 2026

November 11, 2026

postinstall.sh sudoers bug fixed in AcreetionOS-Xlibre

AcreetionOS‑Xlibre’s postinstall.sh now honors the pwfeedback sudoers edit, ending a silent failure that left user privacy tools unconfigured. The fix landed in a recent commit that added proper sudoers handling for the pwfeedback package, so new installs will automatically set up the feedback daemon without manual steps.

Development The change was made by the core team after community reports that the sudoers edit was silently ignored, causing privacy‑feedback services to be missing. You can see the exact fix in the commit history on the GitLab instance. If you’re curious about the other recent dev work, the homepage hero section was updated via PR #627 from Alisonpinto, and the CI pipeline now passes -R to gh release create for faster ISO publishing.

Community Three new stable kernels are out this week: Greg Kroah‑Hartman released 7.3.4 and 6.18.63, giving users the latest bug fixes and security patches. Firefox 160 arrived with performance tweaks and improved privacy controls, and AlmaLinux rolled out a batch of security updates covering curl, glibc, nodejs, qt5, ruby, and more. All of these updates are now available in the usual repository mirrors.

Tip of the day After a fresh AcreetionOS‑Xlibre install, remember to run sudo usermod -aG pwfeedback $USER to ensure the privacy‑feedback service is properly linked to your account. You can also verify the configuration in /etc/sudoers.d/pwfeedback and check the full changelog for any additional post‑install steps at https://acreetionos.org/changelog.html. The official docs walk you through the full setup, so visit https://acreetionos.org/docs.html for a step‑by‑step guide. Want to create a USB install image? Grab the latest ISO from https://acreetionos.org/flash.html and start experimenting right away.
