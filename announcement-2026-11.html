AcreetionOS 1.0 -- November 2026 Snapshot Released

November 11, 2026

AcreetionOS is Arch Linux with a safety buffer -- a beginner-friendly Cinnamon desktop where every update is tested for a week before it reaches you, X11 and XLibre stay alive, and nothing about you is ever collected.

We have refreshed the AcreetionOS ISOs for November 2026. All three editions are rebuilt from the current package set:

  • AcreetionOS 1.0 (Cinnamon, X11) -- refreshed November 11, 2026, 2.35 GB
  • AcreetionOS XL 1.0 (Cinnamon, XLibre) -- refreshed November 11, 2026
  • AcreetionOS Wayland Experimental 1.0 -- refreshed November 11, 2026, 2.34 GB

What is in this snapshot

  • The full current AcreetionOS package set, through the one-week testing buffer as always: every package in this build soaked in our curated repository before release, so a fresh install starts from software that has already survived a week of testing.
  • Linux kernel 7.2.15 and the Cinnamon 6.8 desktop -- 860 packages in the build.
  • The Calamares installer with sensible defaults.
  • X11 and XLibre editions unchanged in spirit: both stay first-class, because Wayland still is not the answer for every machine.
  • No telemetry, no tracking, no accounts, no ads. Free forever, open source under GPL v3.

Already running AcreetionOS? You do not need to reinstall. AcreetionOS is a rolling release -- this snapshot is the fresh-install image, and a normal update brings an installed system to the same place.
