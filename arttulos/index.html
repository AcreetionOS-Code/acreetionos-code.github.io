ArttulOS

An immutable, containerized operating system built on AcreetionOS technology. Atomic updates, read-only root filesystem, and container-native workloads — designed for systems that must stay running and must stay secure.

Source Code Join Discord

🔒 Immutable Root

The root filesystem is mounted read-only. Nothing changes it without an explicit atomic update. No config drift, no surprise modifications, no "what happened to my system?"

📦 Container-Native

Applications run in isolated containers via Docker/Podman with pre-hardened profiles. The host stays pristine — apps live in their own worlds with their own dependencies.

♻️ Atomic Updates

Updates are applied as whole-image swaps. Either the update succeeds entirely, or it rolls back automatically. No partial upgrades, no dependency hell, no broken systems.

🛡️ Security by Default

SELinux enforcing, read-only /usr, no setuid binaries, no world-writable paths, and automatic CVE scanning via GitHub Actions. The attack surface is minimal by design.

⚡ AcreetionOS Base

Built on the Arch Linux foundation via AcreetionOS — you get the performance of rolling releases with the stability of an immutable layer. Pacman runs in a transient overlay.

🔄 Declarative Config

System configuration is declared as code — network, users, services, firewall rules. Rebuild from the same config anywhere and get identical results. Reproducible infrastructure.

Specifications

  • BaseAcreetionOS / Arch Linux (rolling)
  • Root filesystemRead-only ext4 with overlayfs for transient writes
  • Update mechanismA/B atomic image swaps with automatic rollback on failure
  • Container runtimePodman with rootless mode; Docker via compatibility layer
  • Init systemsystemd with custom immutable targets
  • SecuritySELinux enforcing, read-only /usr, no setuid by default
  • DesktopOptional — deploy via container (Cinnamon, GNOME, or none)
  • StateActive development — alpha milestones on GitHub
