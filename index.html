AcreetionOS

Arch Linux, made approachable.

AcreetionOS is a user-friendly, privacy-focused Linux distribution based on Arch Linux. It features the Cinnamon desktop environment, XLibre stability, and a curated selection of tools designed for performance and repository sovereignty.

Our Mission

AcreetionOS bridges the gap between the power of Arch Linux and the simplicity everyday users expect. We curate a stable, pre-configured, and beautiful desktop experience — making the Arch ecosystem accessible to everyone from students to developers.

This project is made possible by the incredible work of the Arch Linux developers and the broader open-source community. We see ourselves as curators, adding convenience, rigorous testing, and thoughtful design to create a cohesive operating system for all.
