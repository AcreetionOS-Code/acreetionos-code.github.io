# AcreetionOS Website - Search Engine Optimization Policy
# Allow all search engines + AI assistant/search bots (so the site gets
# cited in ChatGPT/Claude/Perplexity answers), block AI *training* bots
# and scraper-only crawlers from ingesting the site into models.
#
# Crawl budget: every allowed crawler is steered away from non-content
# paths (API endpoints, JSON data, raw markdown, build artifacts) so
# crawl budget is spent on the 23 real HTML pages. Note: per the
# robots.txt spec, a specific User-agent group OVERRIDES the catch-all
# "*" group, so the crawl-budget rules are duplicated into every
# allowed group below — that is intentional.

# ------------------------------------------------------------------
# BLOCKED: AI training / large-scale scraping crawlers
# These ingest content into model training sets. Content stays out.
# ------------------------------------------------------------------
