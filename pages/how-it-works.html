AcreetionOS · open disclosure

How this browser works

A plain-English, 100%-transparent explanation of every privacy decision baked into this profile. Nothing here is hidden. Nothing here is a middle-man trick.

🚫 No telemetry to Mozilla or Google. Firefox's telemetry, studies (Normandy/Shield), crash reporter, Google Safe Browsing providers, and Pocket recommendation feeds are all switched off. Search uses DuckDuckGo; nothing reports back.

1. The homepage is cached (and clearly disclosed)

What we do

Your homepage is a locally cached copy of acreetionos.org — it loads instantly and works offline. Every 4 days it pulls the latest live version, validates it, backs up the old one, and swaps it in. If a refresh is invalid, the previous good copy is restored.

How you can tell

A small ⓘ bubble sits in the bottom-right corner whenever you're looking at a cached copy. Hover or click it to read: "Cached version" — it even tells you to press Ctrl + Shift + R (Windows/Linux) or Cmd + Shift + R (macOS) to force the live page.

2. The real site always stays live

When you actually type or visit https://acreetionos.org, you always get the live website — the cache never replaces the real address. The cached copy is only the homepage, and only the homepage.

3. Firefox's own backend is intercepted and absorbed in-browser

What we do

In this browser we intercept Firefox's built-in network calls to Mozilla — the account/signing endpoint (accounts.firefox.com), telemetry (telemetry.mozilla.org), the add-on store (addons.mozilla.org), and related channels — and absorb them inside the browser itself. Nothing is forwarded to Mozilla, and nothing is forwarded to any external AcreetionOS service either.

Secure by construction

No network port is opened anywhere and no daemon runs on your machine. The interception happens in a privileged-but-sandboxed extension context that web pages cannot reach, so there is nothing a bad actor could script or probe. Blocked requests are recorded only in a private, on-device log.

What that means

Because extension signing is ours and the add-on channel is closed, this browser loads only third-party extensions we ship, and its backend never talks to Mozilla. You won't get a random "Touch your security key to continue with accounts.firefox.com" prompt: that endpoint is absorbed here, and passkeys are handled by your third-party password manager (e.g. Proton Pass), never by a dead built-in store.

4. Only third-party extensions load

What we do

Firefox's built-in add-on store and discovery channels are turned off (extensions.getAddons.showPane = off). The only extensions that run in this browser are ones we ship and pin in the profile — yours. We don't use Mozilla's add-on catalog at all.

4b. Three modes: Cached · AI · Live (toolbar toggle)

A single toolbar button next to the search bar cycles the browser through three modes, shown by its icon:

• CACHED — top sites load from a locally-archived, encrypted snapshot. Every cached page carries a CACHED badge and a note that to see or input live data you switch to LIVE. A background job gradually archives sites through the day from the Wayback Machine (never all at once), never repeating a site unless it has no snapshot from the last 7 days.

• AI — the browser asks our server for the latest version of the site. The server does the fetching and holds all AI keys; your browser never sees any API key. The result is stored encrypted as a fresh cached snapshot.

• LIVE — normal browsing; nothing is cached, nothing is stripped.

5. DNS, search & privacy defaults

• DNS over HTTPS to 9.9.9.9 (Quad9) with 1.1.1.1 (Cloudflare) as the switchable option.

• Default search is DuckDuckGo; Google/other engines are removed from the bar.

• Address-bar suggestions for bookmarks, history, tabs, top-sites and searches are off.

• Firefox Sync is fully disabled; the browser never restores or uploads your last session by default.

• The built-in password manager is disabled for being unsafe; credentials live in your external manager.

6. Sites & appearance

• The whole browser UI is themed to the AcreetionOS design — dark surfaces, green accents, including about: pages. Extensions are forced to adopt the same theme.

• Tools that restyle the web (like Dark Reader) are per-site and opt-in, so we never break or secretly recolor someone's page.
