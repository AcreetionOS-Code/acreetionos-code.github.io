Why AcreetionOS Is Great for Beginners

1

Graphical Installer

No terminal commands needed to install. The Calamares installer guides you through partitioning, user creation, and setup with an easy-to-follow graphical interface. Just click next.

2

Familiar Desktop Environment

Cinnamon desktop looks and feels like Windows — a taskbar, a start menu, system tray, and window management that you already know how to use. No learning curve for the desktop.

3

Everything Works Out of the Box

Pre-installed applications include a web browser, file manager, text editor, media player, and office tools. Wi-Fi, Bluetooth, and audio are configured automatically on most hardware.

4

Graphical Software Manager

Pamac provides a graphical interface for installing thousands of free applications. Browse categories, search by name, and install with one click. No terminal commands needed.

Getting Started in 5 Minutes

1

Download the ISO

Head to our downloads page and grab the Cinnamon Edition ISO. It's about 2GB.

2

Flash to USB

Use the Acreetion Media Writer or Balena Etcher to create a bootable USB drive.

3

Boot and Install

Reboot your computer, select the USB drive, and follow the on-screen installer. That's it.
