System Requirements

AcreetionOS is designed to run on a broad range of hardware, from legacy machines to modern workstations. Review the specifications below to determine compatibility with your system.

Minimum

Processor 64-bit x86_64, 1.5 GHz+ x86_64
Memory 2 GB RAM
Storage 20 GB free space
Graphics Any GPU, 256 MB VRAM
Integrated graphics supported
Display 1024 x 768
Boot Mode UEFI or Legacy BIOS

Recommended

Processor Dual-core 64-bit, 2.0 GHz+ x86_64
Memory 4 GB RAM or more
Storage 40 GB+ SSD (NVMe preferred)
Graphics Dedicated GPU, 512 MB+ VRAM
Intel, AMD, or NVIDIA
Display 1920 x 1080 or higher
Network Ethernet or Wi-Fi

Hardware Compatibility

Intel Processors

  • Core 2 Duo and newer
  • Pentium 4 and newer (64-bit)
  • Celeron, Atom (x86_64 only)

AMD Processors

  • Athlon 64 and newer
  • Ryzen series, EPYC, Threadripper

32-bit (i686) ISOs are built from the Arch Linux 32-bit repositories but are provided as-is without QA testing.

We compile 32-bit (i686) ISOs using the upstream Arch Linux 32-bit repositories. We do not maintain our own package repos for 32-bit. These builds are provided as-is for testing, education, and automated deployment. 32-bit hardware and software combinations vary widely and our testing capacity is limited. If you run into issues, community knowledge and the Arch32 repos are your best resources.
